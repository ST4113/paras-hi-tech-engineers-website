# Paras Hi Tech Engineers — Full-Stack Business Website

A full-stack client website developed for **Paras Hi Tech Engineers**, an industrial spare-parts supplier serving heavy earthmoving, mining, construction, material-handling and industrial equipment businesses.

🌐 **Live website:** https://parashitech.in/

## About the Client

Paras Hi Tech Engineers supplies spare parts and components for heavy machinery and industrial equipment. Its product areas include:

- Radiators and cooling systems
- Hydraulic oil coolers
- Engine spare parts
- Air-conditioning spares and components
- Truck body spare parts
- Parts for earthmoving, mining, construction and material-handling equipment

The website provides an online product catalogue and a way for prospective customers to explore product information and contact the business.

## Website Overview

This is not only a static frontend website. The project includes frontend development, backend APIs, database integration and an administrative panel for managing product information dynamically.

### Public Website

- Responsive business website for desktop and mobile
- Company and business information pages
- Product catalogue and product detail presentation
- Product information organised for customer discovery
- Customer enquiry and contact pathways

### Backend and Data Management

- PHP backend APIs
- SQL database integration
- API-driven product data
- Dynamic product management through an admin panel
- Administrative workflows for maintaining product catalogue information

### Admin Panel

The administrative panel allows authorised administrators to manage product information without manually editing the website's frontend code. Product catalogue content is maintained dynamically through the backend and database.

## Development Scope

- Full-stack website development
- Frontend UI and responsive implementation
- PHP API development and integration
- SQL database design and integration
- Admin panel development
- Dynamic product catalogue management
